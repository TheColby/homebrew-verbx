# TheColby Verbx

## How do I install these formulae?

`brew install thecolby/verbx/<formula>`

Or `brew tap thecolby/verbx` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "thecolby/verbx"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
